# 현재 작업 상태

갱신일: 2026-10-04 (한국 시간)

## 목표

사무실 두 곳과 집에서 GitHub, Google Drive, 클라우드 환경을 이용하여 이어서 작업합니다.

## 완료

- 프로젝트 기본 구조와 AI 작업 규칙 작성.
- 작업 시작·종료 및 자료 버전 관리 절차 작성.
- 자료 매니페스트와 로컬 캐시 무결성 검사 도구 작성.

## 진행 상태

- 자료 목록은 비어 있습니다. 실제 Drive 연결과 파일 전송은 아직 구성하지 않았습니다.
- 서비스나 앱은 아직 없습니다. 기술 스택과 첫 번째 실제 작업을 정해야 합니다.
- 초기 구성의 원격 게시 상태는 아래 명령으로 확인합니다. 작업 중 변경은 Git 상태를 먼저 확인합니다.

## 다음 행동

1. 프로젝트용 Google Drive 폴더를 지정합니다.
2. 사용자 계정 종류(개인 Drive 또는 조직 Shared Drive)에 맞는 인증 방식을 정합니다.
3. 작은 실제 파일 하나를 등록하고 다운로드·체크섬 검사를 검증합니다.
4. 첫 실제 프로젝트 작업을 시작합니다.

## 재개 명령

```bash
cd /workspace/hanuri
git status --short --branch
git fetch origin
python3 scripts/check_workspace.py
```

## 검증 및 게시

- 기본 매니페스트 검사 통과 (현재 실제 등록 자료 0개).
- 임시 샘플 검증 4개 통과: 정상 파일 허용, 동일 크기의 손상 파일 거부, 누락 파일 거부, 상위 디렉터리 경로 거부.
- Google Drive 실제 인증·다운로드·업로드는 미검증.
- 별도 패키지나 상시 서비스는 필요하지 않음.
- 원격 게시 확인: `git ls-remote origin refs/heads/main`과 `git log -1 --format=%H` 비교. 로컬 변경은 `git status --short --branch`로 확인.
