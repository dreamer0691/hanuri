## 2026-10-04: 저장소와 자료 분리

코드와 작업 이력은 GitHub, 대용량 자료는 Google Drive, 실행 환경은 클라우드에 둡니다. 100TB 전체를 작업 머신에 동기화하지 않고 필요한 파일만 캐시에 준비합니다.

자료는 파일 ID, 버전, SHA-256으로 참조합니다. 최신 자료를 확인한 다음 사용한 버전을 기록하여 과거 작업도 재현할 수 있게 합니다. 파일 ID만으로는 변경 전 내용을 복원할 수 없으므로 중요한 원본은 별도 버전 파일로 보존합니다.

현재는 Python 표준 라이브러리로 검사 도구만 구성합니다. 앱 프레임워크와 Drive 인증 방식은 실제 용도와 계정 종류를 확인한 후 정합니다.
